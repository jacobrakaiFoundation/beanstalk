# App Store screenshot plan

Capture real Release builds with live FDA data. Do not use fictional/demo records, notification mockups, status-bar edits, or claims that exceed the tested build.

## Required device sets

- **Large iPhone:** current App Store Connect 6.9-inch accepted size, captured from the largest supported iPhone simulator/device.
- **Small iPhone QA:** 5.4-inch iPhone layout for compact-screen verification. Upload it only if App Store Connect offers or requires that display class at submission time.

Check Apple's current [screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications) before capture; accepted display classes change over time.

## Capture rules

- Use the same approved copy, real records, date format, and feature state across both size sets.
- Keep the app's cream-and-forest branding visible; include at least one dark-appearance screenshot after the core light set if space allows.
- Make captions readable without covering source fields, badges, or navigation. Do not place the FDA logo or imply government endorsement.
- Show “Published,” “Initiated,” and “Retrieved” only where the source provides them; never substitute one date for another.
- Export lossless PNGs, inspect at 100%, and verify no personal notification previews, device names, tokens, debug controls, or placeholder URLs appear.
