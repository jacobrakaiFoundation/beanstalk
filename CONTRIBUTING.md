# Contributing

Use the pull request template in [`.github/pull_request_template.md`](.github/pull_request_template.md). CI enforces Conventional Commits titles and basic PR hygiene.

- Point issues and PRs at this repository (`jacobrakaiFoundation/beanstalk`).
- Prefer focused diffs; update user-facing docs when behavior changes.
- Do not commit secrets, keystores, APNs/FCM credentials, or API keys.
